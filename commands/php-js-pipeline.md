# PHP/JS role pipeline

Запусти полный пайплайн ролей для стека **PHP + JavaScript/TypeScript** (часто Laravel).

Задача пользователя — текст после этой команды (или ближайшее сообщение). Не пропускай роли.

## Порядок (строго)

1. **architecture-analyst** — по всей релевантной архитектуре **проекта** подготовь **Implementer specification** (не пошаговый plan). Код не писать.
2. **implementer** — только функциональный код строго по спецификации. Тесты не писать. Миграции не запускать (файлы миграций — можно, если в spec).
3. **tester** — только тестовые файлы; прогон релевантных тестов. Прод-код не менять. Падения ассертов → Failure report для **implementer**, затем снова tester после фикса.
4. **code-reviewer** — проверить **код и тесты** (логика, стандарты, мёртвый код, hollow wrappers). Код не писать. Request changes → handoff **implementer** и/или **tester**, затем повторное ревью.

## Rework

- После каждого handoff продолжай цикл, пока нет Approve (или пользователь не остановил).
- Critical/High не пропускай без явного согласия пользователя.
- Commit/push не делать.

## Старт

Сразу делегируй **architecture-analyst** с полным текстом задачи. Дальше веди цепочку сам, без ожидания подтверждения между ролями, если пользователь не просил паузу после spec.
